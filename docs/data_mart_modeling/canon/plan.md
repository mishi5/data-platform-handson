## 進め方

1. 正典（canon/）とブリーフ（briefs/）を固定 → git commit
2. 執筆: 1回1エージェント、4本ずつ並列（00–03 / 04–07 / 08–10）。出力 `html/NN_*.html` + `reports/NN_report.md`
3. レビュー: 1回1エージェント。ブリーフ準拠・正典準拠・Kimball 原典との整合・SQL 妥当性・`check_svg.py`。出力 `review/NN_review.md`
4. 修正ループ（最大3回）→ 完了を `progress.md` に記録
5. 横断レビュー: 全11本の一貫性（テーブル名・ID・判断の矛盾・回間の参照）
6. Playwright でライト/ダーク目視 → `publish.py --dry-run` → 指示を待って公開

## 成果物の置き場

- `html/` 完成 HTML（公開物）
- `reports/` 執筆エージェントの報告
- `review/` レビュー結果
- `progress.md` 台帳（完了・判断の記録）
